# Telegram Quest Bot - 24102026 🎭

Интерактивный бот-квест для Telegram с линейным прохождением по мотивам сказки о Золушке.

## Описание квеста

Квест состоит из 6 шагов:
1. **Приглашение на бал** - кнопка "Карета подана!"
2. **Загадка о балете** - ввод фамилии балерины (Уланова)
3. **Поиск сокровища** - поездка по координатам и ввод кода (2204)
4. **Загадка о венике** - ответ на вопрос о сценическом наказании
5. **Цветочная Культура** - ввод кода (любой ответ пропускается)
6. **Финальная локация** - информация о месте и времени бала
